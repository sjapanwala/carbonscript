# CarbonScript

**CarbonScript** is a simple, flexible programming language inspired by C. It is designed for developers of all skill levels, with an easy-to-understand syntax and powerful features for building a variety of applications.

## Features

- **Readable Syntax**: CarbonScript's syntax is clear and intuitive, making it easy for beginners to learn while still being powerful enough for experienced developers.
- **Variables**: Supports mutable and immutable variables, as well as temporary variables.
- **Control Flow**: Includes basic control flow mechanisms like `if`, `else`, and `default` statements, as well as loops.
- **Functions**: Define and call functions with ease, supporting both functions with return values and void functions.
- **Predefined Variables**: Includes useful variables such as `errorlevel`, `uname`, `version`, and `rand` for random number generation.
- **Built-in Functions**: Includes basic arithmetic functions like `add`, `sub`, `mult`, and `div`.
