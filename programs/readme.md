# Welcome To Programs!

these are all programs i have built using carbonscript, they contain questions from

- leetcode
- project eular
- common data structure questions
- some programs i wanted to make myself!

### 1. Calculator

run `calculator.car` to use a calculator that has the 4 common arithmatic operations (+,-,*,/)

### 2. Sum of Even Fibonacci Sequences

this is a **Project Eular** question (question #2). "Find the sum off all even numbers in a fibonacci sequence"

run `evenfib.car` to run the sum of 50 iterations in the fibonacci sequence

### 3. Fibonacci

run `fibonacci.car` to get the first 50 iterations of the fibonacci sequence.

### 4. FizzBuzz

is a **LeetCode** question. asks, if `i` is divisible by `3` write `Fizz`, if disible by `5` write `Buzz`, and if divisible by both, `3 and 5` write `FizzBuzz`

run `fizzbuzz.car` to try it out with 50 iterations

### 5. Guessing Game

run `guessing_game.car` to play a game to guess a number through various difficulties

### 6. Sum of Multiples of 5 or 3

this is a **Project Eular** question (question #2). "Find the sum off all the numbers divisible by either 3 or 5"

run `multiples.car` to run this program with 1000 iterations

### 7. Reverse an Array

this is a demonstartions i created to showcase how to reverse an array using the *then* new array functions i added

run `reversed_array` to reverse the array
