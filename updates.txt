───────────────────────────CARBONSCRIPT UPDATE - 3.0/25 - 03/3/2025─────────────────────────────
Whats New?
1. File Interactions
      - You can now interact with files using (fset, fwrite, fread, fclear)
      - fset:   set a filename to be created/edited
      - fwrite: write to a file; needs to be fset
      - fread:  read a file; needs to be fset
      - fclear: clear the contents of a file; needs to be fset

2. Libraries are being worked on.
      - libraries can be accessed using `libutils` followed by the library name
      - can be installed using --libutil {libname}
      - all libraries are currenlty only downloadable through the public repo
      - library logic not implemented yet, will be in the structured release next update (03.1/2025)

3. Wiki Update.
      - Added a guide to understand the diagnosis tool on the wiki
      - Added an error code guide; to ensure a seamless error handleing system
