───────────────────────────CARBONSCRIPT UPDATE - 03.1/25 - 03/3/2025─────────────────────────────
Whats New?
1. Added Command Line Arguments
      - default 10 arg slots are generate, if more are used, more are generated.
      - args are encrypted using the carbon-numbering system
      - stored as an array "?args"
      - "?args[0]" will always be the file name being ran
2. Added Carbon-Numbering System
      - strings are handleding by converting into a number, then converted using ascii codes
      - 1181111051000004: 118111105100-> 'void'; 0004 -> length of 'void'
      - strings can be converted to numbers using cnum()
      - numbers can be converted to strings using ascii()
3. Added Misc. Demo Programs
